# Madina Woodworks & Aluminium

A responsive static company website for Madina Woodworks & Aluminium.

## Preview

Open `index.html` directly in a browser. The page uses remote Unsplash imagery for the interior photography and the supplied local logo at `images/Madina_Logo.jpg`.

## Notes

- The enquiry form currently shows a confirmation message in the browser and does not send data anywhere.
- Connect the form submit handler in `script.js` to the company email, WhatsApp flow, or preferred form service once those contact details are available.
